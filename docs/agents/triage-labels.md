# Triage Labels

Use the canonical role strings as local ticket labels. Record the current label in the HTML ticket’s **Status** field.

| Label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The issue needs information from the reporter. |
| `ready-for-agent` | The issue is specified and ready for an agent to implement. |
| `ready-for-human` | The issue requires human implementation. |
| `wontfix` | The project has decided to close the issue without implementing it. |

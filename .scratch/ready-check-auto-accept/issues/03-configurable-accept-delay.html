Summary

Choose how long AFKtor waits before accepting, see the current countdown, and keep the chosen delay across launches.

AFKtor v1 spec

Acceptance criteria

  • On first launch, the setting shows a 3-second delay. Save a different delay and verify it survives restarting AFKtor while auto-accept starts disarmed.
  • An eligible ready check starts a visible countdown. The countdown clears when the check ends, the action is canceled, or the request is sent.
  • Change the delay during an active countdown. Verify that the current ready check keeps its original deadline and the next ready check uses the new delay.

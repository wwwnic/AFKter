01: Observe supported drafts without taking action

Status
ready-for-agent
Blocked by
None

Summary

The player can see supported draft status, assigned role, local action windows, and why automation is observing only. Agents can inspect the same state through existing diagnostics.

Source: approved draft companion design.

Acceptance criteria

  • Verify installed-client queue IDs, role assignment, action identity, timer semantics, teammate pick intent, and draft lifecycle using authoritative API references and replay fixtures. Record which observations still need native verification.
  • Expose draft/role/action/admission status in the tray and bounded read-only diagnostics. Keep the observer independent from UI and retain existing acceptance behavior.
  • Show unsupported queue, unknown role, ended draft, and disconnected states without draft writes.
  • Enabling or reconnecting mid-draft is observe-only until a demonstrably new draft. Disarming cancels session work; enabled state persists across matches but not app restarts.
  • Verify duplicate/out-of-order events, fresh-state admission, and session replacement with deterministic tests; demonstrate a read-only draft progression.

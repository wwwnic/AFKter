Summary

Connect the reviewed editor and shared runtime to one production Avalonia shell with Champions, Settings and tray quick controls.

Source: approved design · implementation plan.

Acceptance criteria

  • Start tray-resident and disarmed. Champions/Settings shortcuts activate the existing window at the requested destination. Close hides and preserves view/runtime state; explicit Exit drains and terminates.
  • Migrate Settings without changing ranges, policy meanings, live edits, reset, save recovery/retry, invalid input or countdown behavior. Advanced timing remains initially collapsed and no Apply/Save button appears.
  • Use the same runtime/plan service across destinations. Preserve existing stored priorities, policy, timing migration, diagnostics and AFKtor technical/storage identities. Do not silently enable draft writes.
  • Remove obsolete WinForms presentation only after replacements are connected. Keep .NET CLI builds, original local icon assets, and the real Linux preview without adding installer/updater or browser dependencies.
  • Integrated tests cover hide/reopen during a held read, shared unsaved plans and retry, repeated navigation, incomplete input and explicit shutdown. Run the full Release suite/build and real Linux editor flow.
  • Record occasional Windows tray, focus, drag/drop, DPI/Narrator and packaging checks as pending if unavailable. This work does not claim completion of original draft-companion ticket 07.

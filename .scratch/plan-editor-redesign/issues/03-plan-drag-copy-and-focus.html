Summary

Make direct manipulation reliable and discoverable while preserving the same plan semantics as click and keyboard commands.

Source: approved design · implementation plan.

Acceptance criteria

  • Drag from the catalog to insert, within a list to reorder, and between lists to copy without removing the source. Cross-pick/ban copies follow the same rule.
  • Use a movement threshold, clear insertion/target feedback, correct copy/move effects and overflow autoscroll. Cancelled/outside drops publish no revision.
  • Resolve current stable identities at drop. Stale source/anchor changes fail safely; destination duplicates preserve order and reveal the existing entry.
  • Selection, focus and visibility follow the affected entry. Search owns text-editing keys: Delete/arrows in search must never remove/reorder plans.
  • Real shared-control tests and native Linux interaction checks demonstrate pointer/keyboard paths, long-list insertion, Escape cancellation, duplicates and exactly one committed revision.
